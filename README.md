# E-commerce SQL Analysis

SQL queries on sample e-commerce orders.

## Features

- Revenue by product
- Repeat customers
- Monthly revenue change and running total

## Tech stack

SQL, SQLite, Python

## How to run

`python run.py` from this folder. Uses only the Python standard library. Window functions need SQLite 3.25 or newer.

## Project files

- `queries.sql` - analysis queries
- `run.py` - creates sample data and runs the queries

## Notes

The data is randomly generated, so results are not real business findings. The script prints up to 12 rows per query.
